## Связь ID

`book_id` (например, `RUS-O_07`) — ключ файлов, построен из id в CSV. `kidlit_id` (например, `RUS-O_long_01`) — ID проекта, совпадает с логом адъюдикации. Оба есть в `books.csv`, `book_stats.csv`, `tokens.parquet` и `sentences.parquet`.
